NOTES ON THE MATHEMATICS

図と計算のあいだにあるもの

この試作は 実係数の affine 直線配置を複素化した補集合 M を対象にします。chamber は平面上の領域で、homology の実際のセルそのものを図示しているわけではありません。

1. Flag と chamber basis

F⁰ を含む chamber が ch⁰、F¹ に交わる残りが ch¹、F¹ に交わらないものが ch² です。個数は (1, n, b₂)。ここでは degree の簡単な公式を使うため、F¹ を全ての有限交点の外側に置き、F⁰ を最初の交差の手前に自動設定します。単に generic な直線であっても、この追加条件を満たさなければ計算を止めます。

2. 局所系と Aomoto

Δ(C,D) = ∏Sep(C,D) tᵢ1/2 − ∏Sep(C,D) tᵢ−1/2 と degree ∈ {0,±1} から行列を作ります。実装では基底をスケールして半冪を消した Laurent 行列を使います。tᵢ = exp(saᵢ) の一次項は deg(C,D) ΣSep(C,D)aᵢ で、これが chamber basis による Aomoto 行列です。

Aomoto コホモロジーと任意の局所系コホモロジーは一般には一致しません。

3. Milnor fiber の意味

入力した n 本に無限遠直線 z=0 を加え、Q(x,y,z) = z ∏ᵢ(aᵢx+bᵢy+cᵢz)、N=n+1 とします。計算対象は Q=1 の Milnor fiber です。各 d|N について Q(ζd) 上で計算し、primitive な d 次固有値の次元をまとめて表示します。固有値は幾何モノドロミーのコホモロジーへの引き戻しの規約で、局所系の tᵢ=λ⁻¹ を使います。

整数係数の torsion はこのバージョンでは計算しません。複素固有空間から整数ホモロジーを復元することはできません。

4. Jump loci の意味

dim H¹ = n − rank d⁰ − rank d¹ という条件を使います。block diagonal 行列 B=d⁰⊕d¹ の (n−k+1) 次小行列式が V¹k、または R¹k を定義します。定義行列・rank 条件に加え、Fitting 型の cohomology jump ideal の生成元と、証明済みの C 上の既約成分分解を表示します。Singular で完了した結果と、処理上限による部分計算・未分解を区別します。J 自体の scheme 構造と、根基の成分分解は別に表示します。再現用 Singular スクリプトも書き出せます。

編集履歴・直線の削除

図の上の「戻す」「やり直す」は、このページで行った作図・方程式変更・flag・直線の回転や削除・表示操作を50段階までたどれます。新しい操作を行うと、その先のやり直し履歴は消えます。Ctrl / ⌘ Z で戻す、Ctrl Y / ⌘ Shift Z でやり直す。入力欄内では通常の文字編集を優先します。「線を選択」で直線を押し、削除ボタンか図にフォーカスした状態で Delete キーを押すと、その直線全体を削除します。各直線のモノドロミー・重みも一緒に除き、復元時には元の直線と値を戻します。履歴はページを再読み込みするとリセットされます。

Intersection poset

非空の交差を逆包含で順序づけます。Affine は ℝ²・各直線・有限交点。Cone は H∞ を含む ℝ³ の部分空間で、rank 2 は射影交点に対応する直線です。幾何的半束／束、rank・次元・Möbius 関数、Whitney 数、Boolean 性、modular 性、supersolvable 性、modular chain を正確に表示します。Face poset とは別のデータです。

図の回転・直線の回転

「図の回転」のスライダーと ↶ / ↷ は表示の向きを変えます。「flag を下で水平に」で全有限交点が上側に来る向きにそろえます。必要なら flag を外側に取り直します。「直線を回す」では線か丸いハンドルをドラッグして編集します。近い交点を初期の支点にし、別の交点を押すかオレンジの支点をドラッグすると変更できます。Shift で画面上の15°刻みにそろえ、矢印キーで1°（Shift で15°）回せます。放すと交点・chamber・各計算を更新し、flag を外側に設定します。支点の座標は正確に保ち、方向は有理数で近似します。複数の交点が分かれたり、平行性が変わったりすることがあります。Esc で操作を取り消し、「戻す」で編集前へ戻れます。

Face poset・Magnitude

Affine の全 face、または H∞ を含む cone の oriented matroid の全 covectors を列挙し、符号の face order と被覆関係を表示します。実次元・本質的な rank・共通 kernel の次元を区別します。Magnitude は Z(q)ₓᵧ=qᵈ⁽ˣ˒ʸ⁾ の逆行列の成分和の規約です。Koizumi の face flag 公式により、実配置の tope graph の整数 magnitude homology を計算します。全次数で torsion-free であり、表示範囲外も Hilbert 有理式で決まります。表の上限は k≤64、ℓ≤128 です。

基本群と群の不変量

吉永の ch² ごとの関係式 R_C と、メリディアンによる正の等質表示を切り替えられます。全関係式について Fox 微分と既存の chamber 行列の一致を Laurent 単元倍を除いて確認します。可換化、H₂(G;Z)、γ₂G/γ₃G、有限性、判定できた可換性を表示。center と直積構造は共点・平行・有限交点が全て2重点の場合だけ証拠付きで表示します。群の一般の同型判定や center 計算は行いません。GAP・SageMath・JSON に書き出せます。

計算の範囲

幾何と Q・有限体・円分体の計算は正確です。複素数を直接指定した局所系だけは浮動小数点で、pivot の絶対値 10⁻⁸ をしきい値にします。位数は N≤60、φ(N)≤24。各カタログ例の有理・実代数的な数体で 20 本まで。最小多項式と分離区間で実埋め込みを指定し、符号・交点の一致を正確に判定します。異なる数体の任意の合成、pseudoline 配置、整数係数の Milnor homology は未対応です。CEL の既知リストで射影21直線以下の66例、吉永の二十・十二面体配置、double star と基本例を収録し、交点数と領域数を出版データと検算しています。描画領域の外の chamber も計算には含めます。

5. 概要・Tope graph・K(π,1)

概要には有限交点と無限遠交点、affine および cone の特性多項式を区別して表示します。Tope graph では 1 成分だけ異なる符号を結びます。Affine と cone（H∞ を含む）のグラフを切り替えられます。

K(π,1) の自動判定は YES / NO / 未判定。Deligne の simplicial 条件、Falk の balanced weights（Cor. 3.10）、modular point の存在は十分条件です。Simple triangle と Yoshinaga consistency の破れは NO の証拠です。consistency を通過しても YES とはしません。Falk の一般版の非一様重み探索は未実装です。図の角や符号・link の有理重みを展開し、判定証拠を JSON で保存できます。

6. net / multinet

指定した射影直線の集合全体を台とする、非自明な構造（d≥2、基点が2点以上）を調べます。H∞を含む全配置、H∞を除いた集合、手で選んだ部分配置を区別します。multinet の重み付き pencil による resonance 空間・character subtorus を、パラメータ写像と飽和した整数関係式で表示します。特殊化した点は Aomoto・局所系の正確計算に読み込めます。pointed deletion の translated family と、文献上の double star の translated component も表示します。これは全成分の自動分解ではありません。全ての部分配置を一括列挙する機能ではありません。分割のクラス次数、基点での重みの釣り合い、クラス内連結性を検証します。

重みは Cartan 行列の正の核から正確に決定し、一定の上限以下に切って探す方法ではありません。許容分割を尽くした場合などに NO、探索上限なら未判定とします。実直線配置の非自明 multinet は3クラスだけを調べれば十分です。4クラスなら4-netとなり、実4-netは存在しません。

7. Alexander 多項式

Affine では入力したn本のメリディアンを全て1に送り、射影閉包の無限遠メリディアンは−nになります。cone では H∞ を含む n+1 個のメリディアンを全て1に送り、Milnor fiber の H₁ 上のモノドロミー多項式を得ます。2つは一般に異なるので、区別して表示します。

第一 Alexander 加群 H₁(無限巡回被覆; Q) の Q[t,t⁻¹] 上の order を原始整数多項式に正規化し、整数因子に分けて表示します。正の free rank があれば Δ=0。根での rank のみから多重度を推測せず、多項式行列の消去または証明付きの局所位数の計算を用います。整数ホモロジーの torsion の計算ではありません。
